# Pila - LiveCoding - ByteBeat

Motor para síntesis generativa de audio mediante código con sintaxis rpn. Orientado para prácticas de codificación en vivo.

> IMPORTANTE: Este software está en estado de desarrollo temprano. De momento no se asegura la compatibilidad con futuras versiones o actualizaciones. Solamente fue testeado en sistemas operativos gnu/linux.

---

En la carpeta `./docs/` está disponible la referencia al motor/interprete y al vocabulario del lenguaje.

Para la creación de este lenguaje y motor he utilizado asistencia de LLM para refactorizar y generar documentación.
